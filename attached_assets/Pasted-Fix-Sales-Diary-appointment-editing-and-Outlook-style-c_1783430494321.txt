PART 3: FIX OUTLOOK-STYLE DIARY DISPLAY

The day/week calendar view must calculate appointment position and height from startTime and endTime.

Source of truth:
- date
- startTime
- endTime

Do not use:
- fixed height
- default 60 minutes
- estimatedDurationMinutes for visual layout

Calendar layout logic:

top = minutesSinceCalendarStart(startTime) * pixelsPerMinute

height = minutesBetween(startTime, endTime) * pixelsPerMinute

Example:
If calendar starts at 07:00 and pixelsPerMinute is 1.2:

Appointment 11:30–16:30:
minutes since 07:00 = 270
top = 270 * 1.2 = 324px
duration = 300 minutes
height = 300 * 1.2 = 360px

The appointment must visually block from 11:30 to 16:30.

Test examples:
- 08:00–08:30 must display as a short 30-minute block
- 09:00–10:00 must display as a 1-hour block
- 11:30–16:30 must display as a 5-hour block
- 09:00–15:00 must display as a 6-hour block
