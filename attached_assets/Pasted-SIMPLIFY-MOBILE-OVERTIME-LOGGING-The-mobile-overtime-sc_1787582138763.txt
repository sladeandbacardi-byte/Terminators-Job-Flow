SIMPLIFY MOBILE OVERTIME LOGGING

The mobile overtime screen is too complicated.

Technicians must not need to select overtime type or calculate anything manually.

Simplify the overtime form.

MOBILE OVERTIME FORM

The technician must only enter:

1. Date
2. Customer name
3. Start time at customer site
4. End time at customer site
5. Notes, optional

Remove or hide:
- Client job dropdown
- Overtime type dropdown
- Related job dropdown as a required field
- Any confusing extra fields

Optional:
If the technician opened overtime from a specific job, prefill:
- Customer name
- Job number
- Site address

But the technician must still be able to type the customer name manually if no job is selected.

FORM LABELS

Use these labels:

Date

Customer Name

Start Time at Customer

End Time at Customer

Notes, optional

Button:
Submit Overtime

OVERTIME CALCULATION

Normal working hours are:

08:00 to 16:00

The app must calculate overtime automatically.

Only time before 08:00 and after 16:00 counts as overtime.

Examples:

06:30 to 08:00
= 1 hour 30 minutes overtime

16:00 to 18:30
= 2 hours 30 minutes overtime

07:00 to 17:00
= 2 hours overtime
because:
07:00 to 08:00 = 1 hour
16:00 to 17:00 = 1 hour

08:00 to 16:00
= 0 overtime

09:00 to 15:00
= 0 overtime

07:30 to 15:00
= 30 minutes overtime

15:00 to 17:30
= 1 hour 30 minutes overtime

VALIDATION

Start time and end time are required.

End time must be after start time.

If calculated overtime is 0, allow the user to submit but show a warning:

No overtime hours were calculated because the selected time falls within normal working hours.

Then allow:
- Cancel
- Submit Anyway

If the time is valid and overtime is calculated, show:

Calculated overtime:
X hours Y minutes
