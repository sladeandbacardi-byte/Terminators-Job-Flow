Update the Contract Includes section for Washroom/Hygiene contracts.

The current Contract Includes screen allows inventory items to be selected, but it does not allow the user to choose whether refills are included in the rental price, charged separately, supplied on demand, or supplied by the client.

This is required.

BUSINESS RULE

For Washroom/Hygiene contracts, a dispenser/equipment item may have a linked refill arrangement.

Example:
A client rents a Paper Towel Dispenser for R200 per month including refills.

Another client rents the same dispenser for R120 per month but pays separately for refills.

Another client rents the dispenser but buys refills from another supplier.

The contract form must support these options.

REFILL RULE OPTIONS

Add a field called:

Refill Arrangement

Options:

- Refills Included in Rental
- Refills Charged Separately
- Client Supplies Own Refills
- On Demand Refills
- Refill Only
- Not Applicable

WHERE TO SHOW THIS

Only show Refill Arrangement for Washroom/Hygiene inventory items that are dispensers, refills, hygiene consumables, or rental equipment.

Examples:
- Hand Sanitizer Dispenser - Automatic
- Hand Sanitizer Refill - 1L
- Paper Towel Dispenser - Wall Mount
- Paper Roll Refill - Premium
- Soap Dispenser
- Soap Refill
- Aerosol A/F Unit
- Aerosol Refill
- Toilet Roll Dispenser
- Toilet Roll Refill
- Urinal Mat

UI CHANGE

For each contract included item, show:

- Item name
- Quantity
- Monthly Rental Price or Unit Price
- Total
- Refill Arrangement
- Linked Refill Item
- Refill Price if charged separately
- Notes

If the selected item is a dispenser/equipment item, show:

Refill Arrangement:
[ dropdown ]

Linked Refill Item:
[ searchable inventory dropdown ]

If the selected item is a refill item only, show:

Refill Arrangement:
[ Refill Only / Refills Charged Separately / On Demand ]

FIELD BEHAVIOUR

If Refill Arrangement = Refills Included in Rental:

Meaning:
The refill is included in the monthly rental price.

Show:
- Linked Refill Item

Hide:
- Refill Price

Set:
- refillIncludedInPrice = true
- refillBillableSeparately = false
- clientSuppliesOwnRefills = false
- stockTrackingRequired = true if linked refill item exists

Job completion:
- technician records refill stock used
- stock reduces
- refill is not billed separately

If Refill Arrangement = Refills Charged Separately:

Meaning:
The dispenser is rented monthly, but refills are billed separately when supplied.

Show:
- Linked Refill Item
- Refill Price

Set:
- refillIncludedInPrice = false
- refillBillableSeparately = true
- clientSuppliesOwnRefills = false
- stockTrackingRequired = true

Job completion:
- technician records refill stock used
- stock reduces
- refill usage becomes billable / ready to invoice

If Refill Arrangement = Client Supplies Own Refills:

Meaning:
The client rents the dispenser from us but buys refills elsewhere.

Hide:
- Linked Refill Item unless optional
- Refill Price

Set:
- refillIncludedInPrice = false
- refillBillableSeparately = false
- clientSuppliesOwnRefills = true
- stockTrackingRequired = false for refill

Job completion:
- do not deduct Terminators refill stock
- do not create refill billing
- show note: Client supplies own refills

If Refill Arrangement = On Demand Refills:

Meaning:
We only supply refills when the client requests them.

Show:
- Linked Refill Item
- Refill Price

Set:
- refillIncludedInPrice = false
- refillBillableSeparately = true when supplied
- clientSuppliesOwnRefills = false
- stockTrackingRequired = true if we supply the refill

If Refill Arrangement = Refill Only:

Meaning:
This line is for refill supply only, not dispenser rental.

Show:
- Refill Price
- Stock Tracking Required

If Refill Arrangement = Not Applicable:

Meaning:
No refill logic applies.
