3. Permissions
Add role-based access control.
The frontend must not be the only protection.
Backend routes/API endpoints must check permissions.

Basic rules:
- super_admin and admin can manage everything.
- manager can view all jobs, edit jobs, assign jobs, and view reports.
- office can create and schedule jobs, view customers, and view quote/document details.
- service_user can view assigned jobs and quote/document details but cannot edit financial/admin settings.
- technician can view assigned jobs, complete checklists, upload photos, and submit vehicle checks.
- read_only can only view dashboards/reports.
