DATA RULES

Each user must have a user type:

userType:
- staff
- admin

or similar.

Mobile technician users:
userType = staff
role = Technician
mobileAccess = true

Office/admin users:
userType = admin
mobileAccess = false unless specifically needed

Filtering rules:

Staff Login:
Only show users where:
userType = staff
or
mobileAccess = true
or
role is Technician / Field Technician / Worker

Admin Login:
Only show users where:
userType = admin
or
role is Managing Member / Admin / Sales / Finance / Service Manager / Service Coordinator / Operations / HR

Do not show the same user in both sections unless explicitly allowed.
