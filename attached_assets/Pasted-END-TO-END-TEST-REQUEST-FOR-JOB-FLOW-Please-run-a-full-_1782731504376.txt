Please run a full end-to-end test of the Job Flow app as if it is being used by the business.

IMPORTANT FOUNDATION

PostgreSQL is the production source of truth.

There must be one central Clients table.

Every record must link back to the central client using clientId.

No duplicate client records may be created across Sales, Service, Jobs, Contracts, Quotes, Rental Contracts, Invoices, Reports, Documents, or Stock.

Do not rely on frontend state only.

Every important saved record must persist after:
- page refresh
- API refetch
- server restart
