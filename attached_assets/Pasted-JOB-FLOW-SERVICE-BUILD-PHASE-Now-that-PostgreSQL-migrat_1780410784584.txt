JOB FLOW SERVICE BUILD PHASE

Now that PostgreSQL migration is complete and the central client database is working, build the next Service Department features in this exact order:

1. Contract scheduling inside the contract form
2. Daily calendar per technician/team
3. Client profile showing all contracts/services
4. Treatment reports saving to client profile
5. Stock usage per technician/job

IMPORTANT FOUNDATION

PostgreSQL is the production source of truth.

Do not use MemStorage for production data.

All new fields and records must be saved to PostgreSQL.

Every service-related record must link back to the central client database using clientId.

Do not create duplicate client records.

Do not create frontend-only fields that disappear after refresh or server restart.

Before adding any new field:
1. Update Drizzle schema
2. Update PostgreSQL table/migration
3. Update API insert/update/select logic
4. Update backup export if relevant
5. Update Data Integrity checks if relevant
6. Test save/search after implementation
