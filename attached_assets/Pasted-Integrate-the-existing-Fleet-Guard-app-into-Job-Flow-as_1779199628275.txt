Integrate the existing Fleet Guard app into Job Flow as a Fleet module.

Do not keep Fleet Guard as a separate app.
Move the Fleet Guard features into Job Flow using Job Flow’s existing authentication, layout, users, roles, and database.

Add Fleet section to Job Flow with these pages:
Fleet Dashboard
Maintenance
Report Issue
Log KMs
Vehicle Inspection
Fuel Fill-up
Vehicle Profile

Use Job Flow users as drivers.
Use Job Flow admin/manager roles for fleet management permissions.

Create or update these database tables:
vehicles
vehicle_assignments
km_logs
fuel_fillups
vehicle_inspections
inspection_items
vehicle_issues
maintenance_requests
service_records

Every fleet record must link to:
vehicle_id
driver_id
date_time

Vehicle Inspection:
Use the Terminators vehicle maintenance checklist as the standard inspection template.
Each inspection item must have:
category
item_to_check
how_to_check
result: Pass / Fail / Not Checked
comments
problem_reported
photo_upload

If any inspection item fails:
create failed inspection alert
create vehicle issue
add it to maintenance queue
send immediate admin email

If all inspection items pass:
do not send immediate email

drivers
