START TECHNICIAN ROLE POLISH

The Technician role is looking better, but there are still permission and data issues.

Technician calendar permissions

For Technician / Worker users, remove or hide:

Create Appointment
Create Job
Edit other workers’ jobs
Print Daily Schedule, unless specifically enabled

Technicians should only be able to:

View their assigned jobs
Open job details
Start Job
Continue Job
Complete Job
Submit Field Diary
Report Issue
Use fleet actions assigned to them
Technician My Jobs page

The My Jobs page must show only jobs assigned to the logged-in technician.

Remove the Create Job button for Technician users.

Keep search and status filters if useful, but filter results by the logged-in technician automatically.

Fix My Schedule page

The My Schedule page currently shows:
0 staff • 0 jobs
No field staff found for the selected filter

This is wrong for Technician users.

For Technician users, My Schedule should not show all staff.
It should show only the logged-in technician’s assigned schedule.

Rename the empty state if needed:
No jobs scheduled for you for the selected day.

My Schedule should show:

Job number
Client

Status
Notes
