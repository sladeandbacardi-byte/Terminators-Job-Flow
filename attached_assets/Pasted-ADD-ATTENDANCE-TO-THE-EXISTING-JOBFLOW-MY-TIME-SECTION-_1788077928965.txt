ADD ATTENDANCE TO THE EXISTING JOBFLOW MY TIME SECTION

Extend the current JobFlow Time & Overtime system with a mobile Attendance feature.

The purpose is for mobile users to record:

- Start of work
- End of work

and for JobFlow to send management an email notification.

Do not create a separate attendance app.

Attendance must be part of the existing:

MY TIME
TIME & OVERTIME

system.

--------------------------------------------------
1. MOBILE MY TIME
--------------------------------------------------

Update the mobile My Time screen.

At the top show:

MY TIME

TODAY

If employee has NOT started work:

[ START WORK ]

After Start Work has been logged:

Started:
07:52

[ END WORK ]

After End Work:

Started:
07:52

Finished:
16:18

Total Attendance:
8 hrs 26 min

Then keep the existing actions:

[ + LOG OVERTIME ]
[ + LOG TIME OFF ]

--------------------------------------------------
2. START WORK
--------------------------------------------------

When the mobile user presses:

START WORK

JobFlow must automatically record:

- Employee
- Current date
- Current server time
- Attendance status
- Created timestamp

Do NOT ask the employee to manually type the time.

Use the server timestamp, not the employee's device-entered value.

After saving successfully show:

"Work started at 07:52"

The Start Work button must then become disabled/hidden for that day.

Do not allow multiple Start Work records for the same employee on the same day.

--------------------------------------------------
3. START WORK EMAIL
--------------------------------------------------

Immediately after the Start Work record saves successfully, send an email to BOTH:

accounts@terminators.co.za
julien@terminators.co.za

Use the SAME reliable JobFlow email system already used for Overtime and Time Off.

Subject:

JobFlow - Work Started - [Employee Name] - [Time]

Example:

JobFlow - Work Started - Garth - 07:52

Email body:

[TERMINATORS LOGO] [JOBFLOW LOGO]

WORK STARTED

Employee:
Garth

Date:
30/08/2026

Start Time:
07:52

Status:
Working

Sent automatically by JobFlow.

--------------------------------------------------
4. END WORK
--------------------------------------------------

Once an employee has started work, show:

END WORK

When pressed, automatically record:

- Current server time as finish time
- Updated timestamp

Do NOT ask employee to manually enter the end time.

Calculate:

TOTAL ATTENDANCE TIME =
End Time - Start Time

Store the total internally as minutes.

Example:

Start:
07:52

End:
16:18

Total Attendance:
8 hrs 26 min

--------------------------------------------------

--------------------------------------------------

Immediately after End Work saves successfully, send an email to BOTH:

accounts@terminators.co.za

Example:

JobFlow - Work Finished - Garth - 16:18

Email body:

WORK FINISHED

Employee:
Garth

Date:

16:18

Sent automatically by JobFlow.

--------------------------------------------------
6. EMAIL DELIVERY
--------------------------------------------------

Do not create another mail system.

Reuse the same working notification service used for:

- Overtime
- Authorised Time Off

Send Attendance notifications to BOTH:

accounts@terminators.co.za
julien@terminators.co.za

If sending to two recipients in one message is unreliable, send two separate emails.

Attendance must still save even if the email fails.

Log email success/failure.

--------------------------------------------------
7. NORMAL WORKING HOURS
--------------------------------------------------

Normal Terminators working hours are:

08:00 to 16:00

Attendance should compare actual start/end times against these working hours.

Examples:

Start 07:52
Display:
Started 8 min early

Start 08:14
Display:
Started 14 min late

Finish 15:45
Display:
Finished 15 min early

Finish 16:20
Display:
Finished 20 min after normal hours

IMPORTANT:

Do NOT automatically convert these differences into Overtime or Time Off.

Attendance is evidence of when the employee started and finished.

Overtime and Authorised Time Off remain separate approved records.

--------------------------------------------------
8. LATE START / EARLY FINISH
--------------------------------------------------

Calculate and display:

Late Start Minutes
Early Finish Minutes

Example:

08:23 start
= 23 min late

15:30 finish
= 30 min early

Admin should be able to see these values in Attendance reports.

Do not automatically deduct these minutes from payroll or Time Balance.

--------------------------------------------------
9. ATTENDANCE WITH TIME OFF
--------------------------------------------------

Attendance must work together with Authorised Time Off.

Example:

Start Work:
08:00

Employee works until:
12:00

Authorised Time Off:
12:00 - 16:00

Employee then attends another job:
16:00 - 17:00

End Work:
17:00

Attendance:
08:00 - 17:00

Authorised Time Off:
12:00 - 16:00

Overtime:
16:00 - 17:00

Do NOT calculate that the employee physically worked continuously from 08:00 to 17:00.

The Time Balance system must continue using approved Overtime and approved Time Off records separately.

--------------------------------------------------
11. ATTENDANCE STATUS
--------------------------------------------------

Possible statuses:

NOT STARTED
WORKING
FINISHED

If employee has started but has not ended work:

WORKING

If employee has not ended work by the end of the day, clearly flag:

MISSING END TIME

Admin must be able to correct this.

--------------------------------------------------
12. ADMIN CORRECTIONS
--------------------------------------------------

Normal mobile users must NOT manually edit their attendance timestamps.

Admin/Management can correct:

- Start Time
- End Time

Any correction must require:

Reason for correction

Example:

"Employee forgot to press End Work."

Record the original and corrected times in the audit trail.

--------------------------------------------------
13. AUDIT TRAIL
--------------------------------------------------

Record:

START_WORK
END_WORK
ATTENDANCE_EDITED
ATTENDANCE_EMAIL_SENT
ATTENDANCE_EMAIL_FAILED

Store:

- Employee
- User performing action
- Date/time
- Original values
- New values
- Correction reason where applicable

14. DATABASE
--------------------------------------------------

Create/use an attendance table linked to the existing employee records.

Suggested:

attendance_records

id
employee_id
work_date
start_time
end_time nullable
total_minutes nullable
late_start_minutes
early_finish_minutes
status
created_at
updated_at
corrected_by nullable
correction_reason nullable

Add a unique constraint so an employee can only have ONE attendance record per work date.

Do not create duplicate employee records.
