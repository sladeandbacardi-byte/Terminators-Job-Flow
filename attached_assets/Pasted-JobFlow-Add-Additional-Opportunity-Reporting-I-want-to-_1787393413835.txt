JobFlow – Add “Additional Opportunity” Reporting

I want to add a new feature to JobFlow called Additional Opportunities.

The purpose is to allow a mobile technician or staff member who is already at a client's premises to quickly report another potential service, maintenance issue, or sales opportunity that they notice while doing their normal work.

This must connect into the existing JobFlow structure and use the existing:

- Clients
- Jobs
- Users
- Leads / Sales
- Quotes
- Photos / attachments where available
- Diary / scheduling
- Notifications

Do not create a completely separate standalone system.

1. Mobile technician button

On the mobile JobFlow screen, add a prominent button:

+ Report Opportunity

Also add this button inside an active job:

+ Additional Opportunity

When opened from an existing job, automatically populate:

- Client
- Client site/address
- Current job
- Technician/user
- Date
- Time

Do not make the technician enter information JobFlow already knows.

---

2. Opportunity form

Keep the mobile form extremely simple.

Fields:

Client

Auto-populated when opened from a job.

If opened from the main mobile screen, allow the user to search/select a client.

Site

Auto-populate from the client/job if available.

Opportunity Type

Dropdown:

- Pest Control
- Washroom Hygiene
- Sanitary Bins
- Deep Cleaning
- Contract Cleaning
- Plumbing
- Electrical
- Hand Dryer
- Fly Machine
- General Maintenance
- Water / Pumps / Tanks
- Waste
- Access Control
- CCTV / Security
- Solar / Energy
- Other

If Other is selected, allow the user to type the service required.

Description

Simple text box:

What did you notice?

Example:

«Ladies bathroom toilet continuously running and leaking into bowl.»

Photo

Allow the technician to:

- Take a photo using phone camera
- Upload an existing photo
- Add multiple photos if necessary

Photos must remain attached to the opportunity and later be visible from the quote/job/client history.

Urgency

Simple options:

- Normal
- Important
- Urgent

Submit

Large button:

Submit Opportunity

The technician must be able to complete this form in less than approximately 30 seconds.

15. Permissions

Mobile technicians

Can:

- Create opportunity
- Add photos
- View opportunities they reported
- View status

Cannot:

- Delete opportunity
- Alter financial values
- Mark opportunity Won
- Create invoices

Sales/Admin

Can:

- View all opportunities
- Assign opportunities
- Change status
- Contact client
- Create quote
- Convert through normal workflow
- Add estimated value
- Record lost reason

Managers

Full access.

16. Mobile design

This feature must work properly on Android mobile screens.

The technician interface should be extremely simple.

Preferred flow:

Open Job
→ Report Opportunity
→ Select Type
→ Take Photo
→ Add short description
→ Submit

Avoid large modal windows that extend beyond the mobile viewport.

Use a full-screen mobile form if necessary.

Buttons must be large enough for easy touch use.

He opens:

+ Additional Opportunity

Plumbing

«Ladies toilet cistern continuously running.»

Presses:

Submit Opportunity

Admin sees:

New Opportunity

ABC Engineering

Plumbing

«Ladies toilet cistern continuously running.»

Customer requests quote.

Admin presses:

WON

IMPORTANT DEVELOPMENT REQUIREMENTS

Before changing the code:

1. Inspect the existing JobFlow database schema.
2. Reuse existing client, job, quote, invoice, user and attachment systems.
3. Do not break existing functionality.
4. Do not create duplicate client or quote systems.
5. Add database migrations safely.
6. Make this work with the existing PostgreSQL database.
7. Ensure desktop and mobile layouts both work.
8. Preserve the existing Terminators/JobFlow colour scheme and UI design.
9. Keep the technician workflow extremely simple.
10. After implementation, test the complete flow:

Technician reports opportunity
→ Admin receives it
→ Admin opens it
→ Quote created
→ Quote accepted
→ Job created
→ Job completed
→ Invoice linked
→ Opportunity marked Won
→ Client Service Wallet updated.
