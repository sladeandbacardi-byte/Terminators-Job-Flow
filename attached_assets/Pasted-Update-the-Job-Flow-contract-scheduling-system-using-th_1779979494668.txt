Update the Job Flow contract scheduling system using the old ZAP screenshots and the hygiene service manager feedback.

The old ZAP system allowed contract jobs to be added to a diary with:
- client
- contract number
- service type
- included date
- price
- start date
- start time
- duration
- fixed time yes/no
- repeat every X
- frequency type
- specific day
- number of times or years
- contract checkbox

Job Flow must keep the useful scheduling logic but make it much simpler and easier to use.

IMPORTANT CONCEPT

A contract must contain its own schedule.

Do not create a separate Service Scheduling main menu item where users manually add schedule entries.

The Contract is the source of truth.

The contract must control:
- how often the service repeats
- which week of the month it happens
- which day it happens
- what time it happens
- what sequence/order it appears in
- which team/technician does it
- whether the time is fixed
- whether the job must be invoiced
- whether stock must be tracked

FIXED TIME

Add a Fixed Time field:

Fixed Time:
- Yes
- No

If Fixed Time is Yes:
The job must appear on the calendar at the selected Start Time.

If Fixed Time is No:
The job can still appear in the route order but the exact time is flexible.

ROUTE SEQUENCE

Add Route Sequence to the contract schedule.

This is especially important for sanitary bins.

Example:
Client: Volkswagen SA
Service Type: Sanitary Bins
Frequency: Monthly
Week of Month: Week 1
Day of Week: Monday
Start Time: 08:00
Route Sequence: 1

The system must use Route Sequence to show the jobs in the correct order.

If Route Sequence is left blank, automatically assign the next available sequence number for that:
- service type
- week of month
- day of week
- assigned team

SCHEDULING RULES BY FREQUENCY

If Frequency is Once-off:
Show:
- Job Date
- Start Time
- Duration
- Assigned Team
- Fixed Time
Hide:
- Week of Month
- Second Day of Week
- Route Sequence optional

If Frequency is Daily:
Show:
- Start Date
- Start Time
- Duration
- Assigned Team
- Fixed Time

If Frequency is 2 x a week:
Show:
- First Day of Week
- Second Day of Week
- Start Time
- Duration
- Assigned Team
- Fixed Time
- Route Sequence

Example:
Monday and Thursday at 08:00

If Frequency is Weekly:
Show:
- Day of Week
- Start Time
- Duration
- Assigned Team
- Fixed Time
- Route Sequence

Example:
Every Tuesday at 10:00

If Frequency is Twice a month:
Show:
- First Week of Month
- First Day of Week
- First Start Time
- Second Week of Month
- Second Day of Week
- Second Start Time
- Duration
- Assigned Team
- Fixed Time
- Route Sequence

Example:
Week 1 Monday at 08:00 and Week 3 Monday at 08:00

If Frequency is Monthly:
Show:
- Week of Month
- Day of Week
- Start Time
- Duration
- Assigned Team
- Fixed Time
- Route Sequence

Example:
Week 1 Monday at 08:00

If Frequency is Every 2 months:
Show the same fields as Monthly, but repeat every 2 months.

If Frequency is Quarterly:
Show the same fields as Monthly, but repeat every 3 months.

If Frequency is Every 6 months:
Show the same fields as Monthly, but repeat every 6 months.

If Frequency is Annually:
Show:
- Month
- Week of Month
- Day of Week
- Start Time
- Duration
- Assigned Team
- Fixed Time
- Route Sequence

If Frequency is On Demand:
Do not automatically place it on the calendar.
Show it under the client profile and contract list as an available on-demand contract.
Jobs must only be created when the client requests the service.
