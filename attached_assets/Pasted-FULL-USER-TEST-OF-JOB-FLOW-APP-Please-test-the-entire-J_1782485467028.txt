FULL USER TEST OF JOB FLOW APP

Please test the entire Job Flow app as if you are a real user in the business.

The goal is to confirm that the app works from beginning to end:

Lead → Quote → Accepted Work → Job → Schedule → Complete Job → Field Diary → Invoice → Finance

Test every major user role and make sure each user sees the correct dashboard, menu items, permissions and workflow.

IMPORTANT:
Use demo/test data only.
Do not delete real data.
Do not use destructive actions unless in demo mode.
If something fails, record the exact page, user role, button and error.

TEST USERS / ROLES TO CHECK

Test login and workflow for these roles:

1. Managing Member
2. Sales Rep
3. Service Manager / Service Coordinator
4. Finance User
5. Technician
6. Admin

For each role, check:

* Can the user log in?
* Does the user land on the correct dashboard?
* Does the left menu match that user’s permissions?
* Can the user only see what they are meant to see?
* Does the Dashboard button open the correct dashboard for that role?
* Does refreshing the browser keep the user logged in?
* Does Switch User / Logout work?

ROLE DASHBOARD RULES

Managing Member:
Must open the Business Overview Dashboard.
Must see Sales, Service, Finance, Operations and Admin.

Sales Rep:
Must open the Sales Dashboard.
Must see Leads, Quotes, Accepted Work, Diary, Clients, Follow-ups, Reports and Email Center if allowed.

Service Manager / Coordinator:
Must open the Service Dashboard.
Must see Jobs, Calendar, Field Diaries, Team Attendance, Clients, Staff, Stock, Suppliers and Purchase Orders if allowed.
If this user also does invoicing, show Finance > Invoices.

Finance User:
Must open the Finance Dashboard.
Must see Invoices, Debtors, Creditors, Sage Export, Reports, Backup & Restore if allowed.

Technician:
Must open the Technician / My Jobs Dashboard.
Must only see:

* Calendar
* My Jobs
* Field Diaries
* Report Issue
* Log KMs
* Vehicle Inspection
* Fuel Fill-up

Technician must not see:

* Sales
* Quotes
* Finance
* Admin
* Staff
* Suppliers
* Purchase Orders
* Full client lists

Admin:
Must see system settings, users, roles, permissions, backup and logs.
