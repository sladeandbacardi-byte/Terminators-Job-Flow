REDESIGN NEW QUOTE WINDOW WITH FULL QUOTE DETAILS

The current New Quote window is too basic.

It currently captures client details, service, frequency, amount and description, but it does not properly capture:
- quantity
- product/service type
- unit price
- line items
- once-off vs recurring work
- contract/rental items
- service frequency details
- VAT
- total calculation

Please redesign the New Quote dialog so it works like a real quote form.

The quote must have two sections:

1. Client Details
2. Quote Line Items / Service Details

SECTION 1: CLIENT DETAILS

Keep the existing “Auto-fill from existing client” picker at the top.

When selecting an existing client, auto-fill:
- Company name
- Contact person
- Phone
- Email
- Address
- Preferred contact

Client fields:
- Company Name
- Contact Person
- Phone
- Email
- Site Address
- Billing Address, optional
- Preferred Contact
- VAT Number, optional
- Company Registration Number, optional

Allow user to edit the auto-filled details before saving.

LINE ITEMS

The quote must allow multiple line items.

Add button:
+ Add Line Item

Each line item must have:
- Department
- Service / Product Type
- Description
- Quantity
- Unit
- Unit Price
- Frequency
- Line Total

Example line item:
Department: Hygiene / Washroom
Service Type: Hand soap dispenser
Description: Supply and service hand soap dispensers
Quantity: 6
Unit: Dispenser
Unit Price: R150
Frequency: Monthly
Line Total: R900 per month

Another example:
Department: Sanitary Bins
Service Type: Sanitary bin rental and service
Quantity: 8
Unit: Bin
Unit Price: R180
Frequency: Monthly
Line Total: R1,440 per month

Another example:
Department: Electrical COC
Service Type: Electrical COC single-phase
Quantity: 1
Unit: Certificate
Unit Price: R1,250
Frequency: Once-off
Line Total: R1,250 once-off

DOCUMENT NUMBER

Every quote must have a document number.

Format:
QT-YYYY-0001

Example:
QT-2026-0007

Show the quote number on:
- Quote card
- Quote detail view
- Converted job
- Invoice if converted later

CONVERSION RULES

If quote is accepted:

If Quote Type is Once-off Service:
Convert to Job.

If Quote Type is Recurring Service:
Convert to Contract and create scheduled jobs.

If Quote Type is Rental Contract:
Convert to Rental Contract.

If Quote Type is Product / Stock Sale:
Convert to Invoice or Job depending on setup.

If Quote Type is Mixed Quote:
Allow user to choose:
- Convert service lines to job
- Convert recurring lines to contract
- Convert product lines to invoice

When converting, carry forward:
- Client
- Site address
- Contact person
- Quote number
- Service/product line items
- Quantity
- Unit price
- Frequency
- Description
- Notes
