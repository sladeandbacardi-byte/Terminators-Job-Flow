RULE BEHAVIOUR

If Consumable Arrangement = Consumables Included:

Meaning:
Consumables are supplied by Terminators and included in the contract price.

Billing:
- do not bill consumables separately
- contract price includes consumables

Stock:
- stock usage must still be recorded
- stock must reduce when consumables are used
- usage is not separately billable

Example:
Rodent bait stations with bait refills included in the monthly pest control contract.

If Consumable Arrangement = Consumables Charged Separately:

Meaning:
Terminators supplies the consumable, but charges the client separately when used.

Billing:
- consumable usage becomes billable
- usage should appear under Jobs To Be Invoiced or invoice extras

Stock:
- stock reduces when consumable is used

Example:
Client rents paper towel dispenser but pays separately for paper towel refills.

If Consumable Arrangement = Client Supplies Own Consumables:

Meaning:
The client rents/uses equipment or receives service from Terminators, but buys the consumables elsewhere.

Billing:
- do not bill consumables
- do not create consumable invoice lines

Stock:
- do not deduct Terminators stock by default
- stock tracking for consumable defaults to No

Example:
Client rents dispenser from Terminators but buys refills from another supplier.

If Consumable Arrangement = On Demand Consumables:

Meaning:
Consumables are supplied only when requested or used.

Billing:
- consumable is billable only when supplied

Stock:
- deduct stock only when supplied

Example:
Extra sani powder supplied on request.

If Consumable Arrangement = Consumable Only:

Meaning:
This line is only for consumable supply, not equipment rental or service.

Billing:
- bill according to price/rule

Stock:
- deduct stock when supplied

If Consumable Arrangement = Not Applicable:

Meaning:
No consumable logic applies.

Use for ordinary service-only contract lines.

JOB COMPLETION / STOCK USAGE

When a technician completes a job linked to a contract, stock usage must follow the consumable arrangement.

If Consumables Included:
- deduct stock
- do not mark consumable as separately billable

If Consumables Charged Separately:
- deduct stock
- mark consumable as separately billable / ready to invoice

If Client Supplies Own Consumables:
- do not deduct Terminators stock by default
- do not bill consumable
- allow note that client supplies own consumables

If On Demand Consumables:
- deduct stock only when supplied
- mark billable if supplied

If technician records Terminators stock on a contract marked Client Supplies Own Consumables, show warning:
"This contract says the client supplies their own consumables. Are you sure Terminators stock was used?"
