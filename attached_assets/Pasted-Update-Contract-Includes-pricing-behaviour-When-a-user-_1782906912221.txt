Update Contract Includes pricing behaviour.

When a user selects an inventory item, product, refill, consumable, dispenser, rental item, or stock item in the Contract Includes section, the system must automatically pre-populate the selling price from Stock Management / Inventory.

CURRENT REQUIREMENT

Stock Management / Inventory is the master source for item pricing.

If an inventory item has a selling price, that selling price must prefill on the contract line.

Example:
Inventory Item:
Hand Sanitizer Refill - 1L
Selling Price: R35.00

When selected in Contract Includes:
Unit Price must auto-fill as R35.00.

PRICE FIELDS ON CONTRACT LINE

Each contract line must include:

- Inventory Item / Service
- Quantity
- Standard Selling Price
- Discount Percentage
- Discount Amount optional
- Final Unit Price
- Total Price
- Manual Price Override
- Notes

UI BEHAVIOUR

When an item is selected from inventory:

1. Fetch the item from PostgreSQL.
2. Read the sellingPrice field.
3. Populate:
   - Standard Selling Price
   - Final Unit Price
   - Unit Price

4. Set Discount Percentage to 0%.
5. Calculate Total Price as:
   Quantity x Final Unit Price

DISCOUNT OPTION

Add a discount field:

Discount %

Default:
0%

If user enters a discount percentage, calculate:

Final Unit Price = Standard Selling Price - discount

Example:
Standard Selling Price: R35.00
Discount: 10%
Final Unit Price: R31.50

Total Price = Quantity x Final Unit Price

MANUAL PRICE ADJUSTMENT

The user must also be able to manually adjust the Final Unit Price.

If the user manually changes Final Unit Price, set:

manualPriceOverride = true

Show a small warning/note:
"Price manually adjusted from standard selling price."

Do not overwrite a manually adjusted price unless the user re-selects the item or clicks Reset Price.

RESET PRICE BUTTON

Add a small button or link:

Reset to Selling Price

When clicked:
- reset Discount % to 0
- reset Final Unit Price to Standard Selling Price
- set manualPriceOverride = false
- recalculate Total Price

CONTRACT LINE DATA

Update contract line items to save these fields:

- stockItemId optional
- itemServiceName
- quantity
- standardSellingPrice
- discountPercentage
- discountAmount
- finalUnitPrice
- totalPrice
- manualPriceOverride
- notes

Make sure these fields save to PostgreSQL.

PRICE SOURCE

Use this logic:

If selected item is from inventory:
- use inventory.sellingPrice as standardSellingPrice

If selected item has no sellingPrice:
- leave price blank or 0
- allow user to enter price manually
- show note:
  "No selling price set for this item."

If selected line is a service-only item:
- use predefined service price if available
- otherwise allow manual entry

PERMISSIONS

Managers/admins can always adjust prices and discounts.

Service managers can adjust prices if their role allows contract pricing.

Technicians must not adjust contract pricing.

If a user does not have price edit permission:
- show the price as read-only
- do not show discount field
- do not allow manual override

CONTRACT SUMMARY

Client Profile > Contracts must display:

- Item / Service Name
- Quantity
- Standard Selling Price
- Discount %
- Final Unit Price
- Total Price

Example:
Hand Sanitizer Refill - 1L
Qty: 1
Standard: R35.00
Discount: 10%
Final: R31.50
Total: R31.50

DATA INTEGRITY

Add checks:

- inventory-linked contract line missing stockItemId
- inventory-linked contract line missing standardSellingPrice
- finalUnitPrice lower than 0
- discountPercentage less than 0 or greater than 100
- totalPrice does not equal quantity x finalUnitPrice
- manualPriceOverride true but finalUnitPrice missing
